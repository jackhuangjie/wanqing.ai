# 晚晴 · 私享 AI 女友体验版

面向成年用户的文字聊天原型。首页开场白明确标为固定文案，后续回复通过服务端请求 OpenAI Responses API，模型错误如实展示，不提供伪造回复。

## 运行与配置

- Node 22+；通过 Sites 提供的安装、预览和构建流程运行。
- 生产环境配置 `OPENAI_API_KEY`（secret）和 `OPENAI_MODEL`（默认 `gpt-6-luna`），密钥只被服务端路由读取。
- `node --test tests/chat.test.mjs` 验证输入边界、记忆隔离、回复解析及错误处理。
- `node node_modules/typescript/bin/tsc --noEmit` 执行类型检查。
- 保留 `.openai/hosting.json` 中既有的项目 ID。密钥不进入源码、Git 或浏览器包。

## 使用与数据

- 首次聊天确认成年及数据发送说明。
- 浏览器以当前 Site 用户标识分区保存最多 180 条消息、12 条记忆、昵称和节奏偏好。最近最多 20 条上下文随请求提交，约 16,000 字上限。
- 记忆由用户明确确认；修改或删除记忆、切换虚拟场景都会隔断旧上下文，避免旧聊天继续携带已删除的资料。
- 清空聊天保留记忆；清除全部数据会删除此浏览器中的记录和偏好；支持 JSON 导出。
- 无跨设备同步、语音通话、定时提醒或主动推送。场景明确标记为虚拟互动。

## 后端边界

当前部署仅站点所有者可访问。API 依赖 Sites 的私有站点访问边界，兼容站点授权服务访问；将站点改为公开前，必须补充 API 用户鉴权和严格的配额计费控制。

Responses API 使用 `store:false`，这不代表供应商完全不保留请求。应用不建立聊天数据库或输出请求日志。为支持重试，同一 Worker 实例可在内存中缓存最近 100 个成功请求及其上下文 5 分钟。缓存过期或实例切换后，重试仍可能产生新的模型调用。

每个 Worker 实例对当前身份进行每分钟 10 次的尽力限流。这不是全局硬额度。模型输出上限 600 tokens，服务端等待上限 45 秒。浏览器“停止”等待不能保证撤回已发送的上游请求。

私享测试版尚未实现生产应用所需的账号数据同步、完整审计、严格成本配额和独立安全评估。

本地开发（Node.js 22.13+）：运行 npm run install:ci，将 .dev.vars.example 复制为 .dev.vars 并填写密钥，运行 npm run dev。
